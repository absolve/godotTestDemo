# Box Head 流场寻路与敌人格子占位演示

这是从 Box Head 重制项目的地图数据与僵尸导航中抽取核心机制制作的独立 Godot 4 演示，不依赖原游戏资源或插件。场景仅使用代码绘制网格、障碍、流场和敌人。

## 运行

用 Godot 4 打开本目录中的 `project.godot`，然后运行项目主场景。

## 场景结构

- `main.tscn` / `main.gd`：绘制地图并统一管理流场、敌人占位与移动。
- `player.tscn` / `player.gd`：玩家目标点及其绘制。
- `enemy.tscn` / `enemy.gd`：单个敌人的绘制；由主场景实例化多个。

## 操作

- 左键：把目标移动到所点格子，并重算流场。
- 右键：在空格上添加或移除障碍，并重算流场。
- `Space`：暂停 / 继续。
- `F`：显示 / 隐藏流场方向箭头。
- `R`：重置演示。

## 展示内容

- 从目标格进行八邻域 BFS，生成距离场；多个敌人可以共用一张流场。
- 每个可达格指向距离更小的邻格，形成指向目标的方向场。
- 静态障碍会阻断传播；对角移动不能穿过两个正交障碍夹成的墙角。
- 蓝色格子表示敌人当前登记的占用格；移动中的黄色边框表示下一步预留格。
- 敌人避开目标格以及其他敌人占用或预留的格子，在目标格相邻处停下；首选流场方向不可走时，改选距离更小的可通行邻格。

实现对应原项目 `MapData.computeFieldMulti`、`MapData.reserveCell` / `releaseCell` 和僵尸的 `navDirection` / `startMove` 思路。这里用离散格与简化插值突出寻路和占位，不包含原游戏的状态机、攻击、物理碰撞等完整行为。
